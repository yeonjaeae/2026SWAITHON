# v2.0 개선 내용 / 2026-11-11

## 이번 작업의 결론

AI 구현에 맞는 연결 코드와 실제 자료를 처리하는 검증·변환·저장 흐름을 추가했습니다. 단일 호스트의 신뢰하는 통합 서버 뒤에서 사용할 수 있도록 구성했습니다. **실제 모델 정확도·현장 시공 가능성·모든 지역 데이터의 존재·무중단 운영을 보증하는 버전은 아닙니다.**

## 프론트/통합 서버의 필수 변경

1. 추천 응답의 recommendation_id를 저장합니다.
2. 선택 API는 `{recommendation_id, candidate_id}`를 보냅니다.
3. 설계 handoff도 recommendation_id/candidate_id를 사용합니다.
4. editable에 source와 review_status를 전달합니다. 실제 검토 완료 전 reviewed로 지정하지 않습니다.
5. 운영 인증 키는 서버에서만 보관합니다. 브라우저에 직접 넣지 않습니다.
6. AI 응답은 normalize-landcover에서 변환하거나 추천 요청의 ai_landcover에 넣습니다. landcover와 중복 입력하지 않습니다.
7. 스냅샷이 만료되면 다시 추천합니다. 고정된 예시 ID를 재사용하지 않습니다.

## 실제 데이터에 대한 개선과 한계

위치가 고정된 데모만 처리하는 구조가 아닙니다. 사용자 영역과 실제 시설 파일을 입력하면 그때마다 교차·점수를 계산합니다. EPSG:4326/3857/5179/5186 변환을 테스트했습니다. 다른 CRS도 pyproj가 지원하고 한국 범위로 유효하게 변환될 때 처리하되, 모든 CRS의 정확도를 검증한 것은 아닙니다.

전체 서비스 범위는 **상위 자료가 준비된 지역**으로 제한됩니다. 현재 동희 격자와 AI 주거지역은 서울 기반이고, AI 영상은 3857이어야 합니다. 서울 밖에서 후보지 모듈만 실행할 수 있어도 누락된 주거지역·격자 데이터를 자동 생성하지 않습니다.

면적은 수평면적입니다. 실제 지형의 경사·고도·지반·토양·배수·공법 적합성을 원한다면 해당 자료와 별도의 평가 모델을 연결해야 합니다. 이 버전은 이를 토지피복에서 추정하지 않습니다.

## 변경하지 않은 것

팀원 AI·환경 효과·녹지 부족 원본 코드는 수정하지 않았습니다. 후보지 API 교체용 폴더를 별도로 완성했습니다. GitHub 업로드/PR/배포는 하지 않았습니다. 실제 시설 경계나 실제 editable을 새로 확보했다고 표시하지 않았습니다.
